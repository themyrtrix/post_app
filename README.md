# Posts App (TypeScript Edition)

A minimal, Apple-inspired full-stack blogging application built with Next.js (Pages Router), Prisma ORM, MySQL, and fully typed with TypeScript.

## Prerequisites

- **Node.js**: v18.0.0 or higher
- **MySQL**: Local database server running on port 3306
